# AI 工具公众号运营台

一个本地运行的公众号内容运营后台，支持选题生成、文章草稿、合规检查、发布排期、多模型配置，以及 Webhook/微信公众号接口适配。

## 启动

```bash
npm start
```

浏览器打开：

```text
http://localhost:4173
```

## 模型

后台提供文字模型和图片模型两套独立配置。文字模型支持 OpenAI、DeepSeek、Kimi、Gemini、通义千问、智谱 GLM、Claude、OpenRouter、SiliconFlow 和自定义中转 API。图片模型支持 OpenAI 图片接口和自定义图片中转。进入“设置”后分别新增配置，再填入 API Key、Base URL 和模型名。

文字模型配置有“拉取模型”和“测试模型”按钮。图片模型配置有“拉取图片模型”和“测试图片模型”按钮。图片模型名不固定，优先从接口拉取，也可以手动填写，例如中转服务支持的 `gpt-image-2`、`grok-imagine-1.0` 或 `gemini-3.1-flash-image`。生成文章时，文字模型负责写稿和返回 `imagePlan`，后端再按计划调用图片模型；如果没有配置图片模型，会使用本地 SVG 配图兜底。

## 配置备份

设置页可以点击“导出配置”下载当前配置。导出文件包含文字模型、图片模型、发布配置以及真实 API Key，请只保存在可信位置。

## 发布

支持四种发布动作：

- 本地标记：只把文章状态标记为已发布。
- Webhook：把文章 JSON 和 HTML 推送到你自己的自动化服务。
- 上传微信草稿：调用公众号草稿接口创建草稿。
- 提交微信发布：创建草稿后提交发布。

微信发布需要公众号具备对应接口权限，并在“设置”里填入 AppID、AppSecret 和封面素材 `thumb_media_id`。排期自动执行需要勾选“允许到点自动执行”，并保持本地服务运行。

## 外链改写

文章页可以填写“外部文章链接”。系统会抓取网页标题、摘要和正文要点，再调用文章模型生成原创公众号稿，并保留参考来源链接。该功能适合做解读、评论、教程化改写，不建议用于逐段洗稿。

找不到 `thumb_media_id` 时，可以在“发布配置”里选择一张封面图，点击“上传封面到素材库”。系统会调用微信永久素材接口上传图片，并把返回的 `media_id` 自动填入封面素材字段。

## 合规边界

系统会拦截破解下载、注册机、激活码、绕过授权、盗版资源入口等内容。软件分享建议写成正版优惠、官方试用、开源替代、工具测评和安全风险分析。
